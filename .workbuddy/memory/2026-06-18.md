## UI/UX + 前后端链路修复（第二轮）

### 问题1: 底部导航栏选中文字不可见
- 根因: 液态玻璃浅色模式下 `.lg-tabbar-label-active { color: #FFFFFF }`（白色字）+ 半透明白色底栏 = 完全不可见
- 修复: light CSS中改为 `color: #0066D6` + `background: rgba(0,102,214,0.10)`；dark CSS保持白色并加蓝色半透明背景

### 问题2: 多页面双重返回键/嵌套
- 根因: LiquidGlassLayout对所有子页面自动渲染sub-page header（含返回键+标题），而页面内部 `<Header showBack={true}>` 再渲染一层
- 修复方案: Header.tsx + MobileHeader.tsx增加液态玻璃上下文检测，`basePath === '/lg'` 时直接 return null
- LiquidGlassLayout主Tab标题跟随选中页变化（"轻淘校园"→"我的"/"广场"/"消息"）
- 一次性修复所有子页面的双重返回键问题（9+页面）

### 问题3: 帖子/商品点击报错
- P0-1: PostDetailPage点赞调用了错误API `/api/notes/${id}/like` → 修复为 `/api/posts/${id}/like`
- P0-2: 后端缺失 `POST /api/posts/:id/like` 和 `POST /api/posts/:id/comments/:commentId/like` → 新增controller+service+route
- P1: Goods "reserved"状态被排除在可见状态外，非所有者看到"商品不存在" → 将'reserved'加入allowlist（替换了错误的'offline'）
- P3: 后端post详情缺少`isLiked`字段 → 新增`findPostLike()`查询 + 评论附加`isLiked: false`

### 问题4: 泛化
- SquarePage FeedItem类型新增'post'，handleClick补充post→/square/post/:id导航
- PostDetailPage从"孤页"变为可正常访问和交互
